Data Utility Functions Documentation

Complete guide for loading, cleaning, analyzing, visualizing, and exporting data

run_sql_query(connection_string, query)

Role: Database query
Description: Executes a SQL query against a database using SQLAlchemy and returns the result as a Pandas DataFrame.
  • connection_string (str): SQLAlchemy connection string
  • query (str): SQL query to execute
Return Type: pd.DataFrame
run_sql_query('postgresql://user:pass@localhost:5432/mydb', 'SELECT * FROM sales;')

load_csv_from_s3(bucket, key, separator=',')

Role: Data loading
Description: Loads a CSV file from an AWS S3 bucket into a Pandas DataFrame.
  • bucket (str): S3 bucket name
  • key (str): Key (path) to the CSV file in the bucket
  • separator (str): CSV delimiter (default ',')
Return Type: pd.DataFrame
load_csv_from_s3('my-bucket', 'data/sales.csv', ',')

handle_missing_values(dataframe, column, strategy, fill_value=None)

Role: Data cleaning
Description: Handles missing values in a specified column using strategies like 'drop', 'fill', 'mean', 'median'.
  • dataframe (pd.DataFrame): Input DataFrame
  • column (str): Column to clean
  • strategy (str): Strategy for handling missing values ('drop', 'fill', 'mean', 'median')
  • fill_value (any): Value to fill if strategy='fill'
Return Type: pd.DataFrame
handle_missing_values(df, 'price', 'mean')

remove_duplicates(dataframe)

Role: Data cleaning
Description: Removes duplicate rows from a DataFrame.
  • dataframe (pd.DataFrame): Input DataFrame
Return Type: pd.DataFrame
remove_duplicates(df)

change_column_type(dataframe, column, new_type)

Role: Data transformation
Description: Converts the data type of a column to integer, float, string, or datetime.
  • dataframe (pd.DataFrame): Input DataFrame
  • column (str): Column to convert
  • new_type (str): Target type: 'integer', 'float', 'string', 'datetime'
Return Type: pd.DataFrame
change_column_type(df, 'date', 'datetime')

rename_columns(dataframe, rename_map)

Role: Data transformation
Description: Renames one or more columns in a DataFrame.
  • dataframe (pd.DataFrame): Input DataFrame
  • rename_map (dict): Mapping of old to new column names
Return Type: pd.DataFrame
rename_columns(df, {'old':'new'})

filter_rows(dataframe, column, operator, value)

Role: Data filtering
Description: Filters rows in a DataFrame based on a condition.
  • dataframe (pd.DataFrame): Input DataFrame
  • column (str): Column to filter
  • operator (str): Operator (==, !=, >, <, >=, <=, contains)
  • value (any): Value for comparison
Return Type: pd.DataFrame
filter_rows(df, 'price', '>', 100)

select_columns(dataframe, columns_to_keep)

Role: Data selection
Description: Keeps only the specified columns in the DataFrame.
  • dataframe (pd.DataFrame): Input DataFrame
  • columns_to_keep (list): Columns to retain
Return Type: pd.DataFrame
select_columns(df, ['id','price'])

join_dataframes(df1, df2, on_column, how='inner')

Role: Data merging
Description: Joins two DataFrames on a common column using inner, left, right, or outer join.
  • df1 (pd.DataFrame): First DataFrame
  • df2 (pd.DataFrame): Second DataFrame
  • on_column (str): Join key column
  • how (str): Join type ('inner','left','right','outer')
Return Type: pd.DataFrame
join_dataframes(df1, df2, 'id', 'left')

group_by_aggregate(dataframe, group_by_col, agg_col, agg_func)

Role: Data aggregation
Description: Groups a DataFrame by a column and aggregates another column using sum, mean, count, std, min, or max.
  • dataframe (pd.DataFrame): Input DataFrame
  • group_by_col (str): Column to group by
  • agg_col (str): Column to aggregate
  • agg_func (str): Aggregation function
Return Type: pd.DataFrame
group_by_aggregate(df, 'category', 'sales', 'sum')

sort_values(dataframe, by_column, ascending=False)

Role: Data sorting
Description: Sorts a DataFrame by a column.
  • dataframe (pd.DataFrame): Input DataFrame
  • by_column (str): Column to sort by
  • ascending (bool): Sort ascending (default False)
Return Type: pd.DataFrame
sort_values(df, 'sales', ascending=True)

get_descriptive_statistics(dataframe, column)

Role: Data analysis
Description: Calculates descriptive statistics (mean, median, std, min, max, count) for a numeric column.
  • dataframe (pd.DataFrame): Input DataFrame
  • column (str): Numeric column for stats
Return Type: dict
get_descriptive_statistics(df, 'price')

display_stats(stats, title=None)

Role: Data visualization / reporting
Description: Displays the contents of a descriptive statistics dictionary in a readable format, with an optional title.
  • stats (dict): Dictionary containing descriptive statistics
  • title (str, optional): Title to display above the statistics
Return Type: None (prints statistics)
display_stats(stats, title='Daily Sales Statistics')

display_head(dataframe, n=5)

Role: Data inspection
Description: Displays the first N rows of a DataFrame for inspection.
  • dataframe (pd.DataFrame): Input DataFrame
  • n (int): Number of rows to display
Return Type: pd.DataFrame
display_head(df, 5)

plot_bar_chart(dataframe, x_col, y_col, title)

Role: Data visualization
Description: Plots a bar chart from the DataFrame.
  • dataframe (pd.DataFrame): Input DataFrame
  • x_col (str): X-axis column
  • y_col (str): Y-axis column
  • title (str): Chart title
Return Type: None (displays chart)
plot_bar_chart(df, 'category', 'sales', 'Sales by Category')

plot_line_chart(dataframe, x_col, y_col, title)

Role: Data visualization
Description: Plots a line chart from the DataFrame, ideal for time-series data.
  • dataframe (pd.DataFrame): Input DataFrame
  • x_col (str): X-axis column
  • y_col (str): Y-axis column
  • title (str): Chart title
Return Type: None (displays chart)
plot_line_chart(df, 'date', 'daily_sales', 'Daily Sales Trend')

save_dataframe_to_csv(dataframe, filename)

Role: Data export
Description: Saves a DataFrame to a local CSV file.
  • dataframe (pd.DataFrame): DataFrame to save
  • filename (str): File path/name for CSV
Return Type: None (saves file)
save_dataframe_to_csv(df, 'output.csv')
