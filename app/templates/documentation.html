unit_saas Documentation

A lightweight, dynamic Python library built to effortlessly process complex pandas dataframes and structured data structures using customized rule-based prompts.

Installation

Install the official package from PyPI using your favorite package manager:

pip install unit_saas

Quickstart

Import the core loader asset into your script implementation:

from unit_saas import loader

Function: loader()

The core execution method responsible for parsing operational data frames and runtime structures against specific prompt conditions before pushing payloads onwards to a chosen listener endpoint.

Parameters

Argument Type Description
security_token String Secure hash generation used to complete server-side API handshakes.
data dict data structured as a dictionary
rules String Natural language instruction sequence detailing transformations to execute.
address String (URL) Target POST address endpoint. Defaults directly to: https://agentic-ai-nt21.onrender.com/call
frame pd.DataFrame Data structured as a DataFrame.
Important Note: Parameters defined dynamically in runtime tracking steps will only render correctly back to systemic outputs if explicitly references/utilized within your logical rules sequence text.

Extending with User Functions

Dynamically load individual python custom extensions or complete modular script directories straight into the pipeline engine using the context rules below.

Load a Specific File

from unit_saas import load_user_functions

# Point to the explicit file system location containing your custom definitions
load_user_functions("/path/to/your/custom_functions.py")

Load an Entire Folder Directory

from unit_saas import load_user_functions_from_folder

# Iteratively pull all processing functions located across a targeted local directory
load_user_functions_from_folder("/path/to/functions/directory")

Complete Example Usage

The template workflow scenario displays loading an initial student dictionary object, transforming it via execution prompts, and submitting safely using runtime access configurations:

from unit_saas import loader

if __name__ == "__main__":

    prompt = """Take the DataFrame df and perform the following steps:
1. Display the first 5 rows of df.
2. Handle any missing values in the column 'Age' by filling them with the mean of the column, storing the updated DataFrame in a variable called 'df_filled'.
3. Remove any duplicate rows from 'df_filled', storing the result in 'df_no_duplicates'.
4. Change the data type of the column 'Age' in 'df_no_duplicates' to integer, storing the result in 'df_typed'.
5. Filter 'df_typed' to include only rows where 'Is_Student' is True, storing the result in 'df_students'.
6. Calculate descriptive statistics (mean, median, std, min, max, count) for the 'Age' column in 'df_students' and store the result in a variable called 'student_age_stats'.
7. Display the contents of 'student_age_stats' with the title "Student Age Statistics".
"""

    data = {
        'Name': ['Alice', 'Bob', 'Charlie', 'David'],
        'Age': [25, 30, 28, 22],
        'City': ['New York', 'London', 'Paris', 'Tokyo'],
        'Is_Student': [True, False, False, True]
    }

    security_token = "089f9d1475e3db7fd6ecc8a218ebd974b40f0b3fcf3d88bc6b6c9b8b6d55444c"

    # Process execution block 
    some_variable = loader(data=data, rules=prompt, security_token=security_token)
    print(some_variable)
